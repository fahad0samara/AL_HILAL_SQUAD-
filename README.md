# نادي الهلال السعودي | الفريق الأول (Al Hilal SFC — First Team Hub)

منصة ويب عربية متكاملة ومتجاوبة (`RTL` · `Mobile-First`) لاستعراض تشكيلة الفريق الأول لنادي الهلال السعودي لموسم **2026/2027**، مصممة بهوية بصرية مستوحاة من الأزرق الملكي وبطاقات الدروع المنحنية مع صور رسمية مفرّغة الخلفية لجميع اللاعبين.

---

## أبرز المميزات | Key Features

- **معرض الفريق التفاعلي (5-Card Perspective Shield Carousel):**
  - عرض جميع **27 لاعباً** في القائمة الرسمية للفريق الأول مع صورهم الرسمية عالية الدقة، بالإضافة إلى **الجهاز الفني** بقيادة سيموني إنزاغي ومساعده ماسيميليانو فاريس.
  - تصفية فورية حسب المركز (الكل، الحراس، الدفاع، الوسط، الهجوم)، وبحث سريع بالاسم أو رقم القميص، مع حفظ اللاعبين المفضلين محلياً.
- **بطاقة تفاصيل اللاعب ومخطط الرادار (Player Profile & SVG Radar Chart):**
  - نافذة تفصيلية (Bottom Sheet على الجوال / Modal على سطح المكتب) تعرض السيرة الذاتية، الأرقام الموسمية، الإنجازات، ومخطط رادار سداسي للقدرات الفنية.
- **الملعب التكتيكي التفاعلي (Kingdom Arena Tactical Pitch):**
  - استعراض التشكيل الأساسي وتبديل الخطط (`3-5-2`، `4-2-3-1`، `4-3-3`) مع إمكانية استبدال اللاعبين مباشرة بين التشكيلة الأساسية ودكة البدلاء.
- **مقارنة اللاعبين (Head-to-Head Comparator):**
  - مقارنة مباشرة بين أي لاعبين في الفريق عبر مخطط رادار مزدوج ومؤشرات إحصائية تفصيلية.
- **مركز النادي المتكامل:**
  - **الرئيسية والمباريات:** عداد تنازلي مباشر للمباراة القادمة، جدول المباريات المقبلة، ونتائج وإحصائيات المباريات السابقة.
  - **جدول الترتيب:** ترتيب دوري روشن السعودي لموسم 2026/2027 وسلسلة النتائج الأخيرة.
  - **التذاكر:** خريطة تفاعلية لمدرجات **المملكة أرينا** مع محفظة تذاكر رقمية وباركود.
  - **المتجر الرسمي:** تخصيص القميص الرسمي بالاسم والرقم مع معاينة فورية وسلة مشتريات متكاملة.

## التقنيات المستخدمة | Tech Stack

- **React 19** + **TypeScript**
- **Vite 8**
- **Tailwind CSS v4**
- **Motion** (Framer Motion)
- **Lucide React**
- خطوط **Cairo** و **IBM Plex Sans Arabic**

## التشغيل المحلي | Getting Started

### المتطلبات
- **Node.js** (الإصدار 18 أو أحدث)
- **npm**

### خطوات التشغيل

1. **تثبيت الاعتماديات:**
   ```bash
   npm install
   ```

2. **تشغيل بيئة التطوير (على المنفذ `3000`):**
   ```bash
   npm run dev
   ```

3. **فحص الأنواع (TypeScript):**
   ```bash
   npm run lint
   ```

4. **بناء نسخة الإنتاج ومعاينتها:**
   ```bash
   npm run build
   npm run preview
   ```
